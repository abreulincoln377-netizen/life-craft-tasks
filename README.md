# Task Harmony

Cria uma lista de tarefas. Cada tarefa deve conter título, prazo, prioridade e conteúdo, além de ser possível selecionar as categorias que pode ser qualquer uma dessas:

- Trabalho
- Atendimentos
- Estudos 
- ⁠ Financeiro
- ⁠Conteúdo/Redes sociais
- ⁠Cursos/Formações
- ⁠Administrativo
- ⁠Pessoal
